# Contributing

Thanks for considering contributing to Roudromoyee Online Clinic.

## Getting Started

1. Fork the repository and clone your fork.
2. Follow the [README setup instructions](README.md#installation) to get the backend and frontend running locally.
3. Create a branch off `main`:
   ```bash
   git checkout -b feature/short-description
   ```

## Making Changes

- Keep pull requests focused on a single feature or fix — smaller PRs are easier to review.
- Match the existing code style in the file you're editing.
- Test your changes locally (both backend and frontend) before opening a PR.
- Never commit `.env` files or real credentials. Use `.env.example` as a template.

## Branch Naming

- `feature/...` for new features
- `fix/...` for bug fixes
- `docs/...` for documentation-only changes

## Commit Messages

Write clear, descriptive commit messages that explain *why* a change was made, not just what changed.

## Submitting a Pull Request

1. Push your branch to your fork.
2. Open a PR against `main` with a description of the change and, if applicable, screenshots for UI changes.
3. Link any related issues.
4. Be responsive to review feedback.

## Reporting Bugs / Requesting Features

Use the issue templates under [Issues](../../issues/new/choose).

## Code of Conduct

Be respectful and constructive. This is a healthcare-adjacent project — treat contributors and the domain with care.
